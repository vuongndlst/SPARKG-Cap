Calibration Pilot — Entity Roles & Directed Relations

Complete this calibration set independently to align on role definitions and visual-evidence criteria before annotating the main evaluation set. Selections are automatically saved in your browser; click Download CSV at any time to export your annotations.

  • Entity Role: Foreground = primary subject essential to a single-sentence summary; Auxiliary = secondary discrete object contributing detail without dominating the scene; Background = amorphous setting, surface, or environmental context.
  • Directed Relation (A → B): Select Yes (Supported) only when the image provides clear visual evidence for the stated predicate (e.g., spatial proximity alone is insufficient for holding). Select No (Unsupported) when contradicted, or Uncertain when occluded/ambiguous.
  • Invalid Box: Select if a bounding box fails to localize an identifiable entity.
