SPARKG-Cap — Blinded Human Evaluation Portal

Self-contained browser interface for independent human verification of intermediate scene-graph semantics (entity roles and directed relations) and downstream paired image captions across the MS-COCO and Flickr30K benchmarks.

Protocol & Blinding Integrity
  • All items are strictly blinded: system provenance, relation lookup tiers, and A/B condition assignments are stripped from this web suite.
  • Each evaluator should enter a consistent Annotator ID (e.g., A1, A2, A3), work independently without consulting reference captions, and export their completed .csv file.
  • Progress is saved automatically in local browser storage so sessions can be paused and resumed safely.
